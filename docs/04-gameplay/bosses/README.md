  `04-gameplay/BOSSES.md`.
- **Pendências de playtest:** marcadas com ⚠️ quando um valor é placeholder
  ou uma decisão de design depende de teste real (ex.: Pavio-Rei fase 2 em
  co-op).

  documentada — não repetida ficha a ficha.
